# 公开使用攻略

## 中文图文新手攻略

[JR Music Studio 新手使用攻略](zh-CN/JR_Music_Studio_Beginner_Guide_CN.html)

涵盖新建歌曲、与 Hermes 讨论方案、YuE2 生成首版、候选试听与版本决策、Style／歌词修订、谱面编辑、MIDI／MusicXML 导出及安装入门。保留作者提供的原始 HTML 与 13 张内嵌截图。

### 如何打开

1. 点击上方攻略链接，在 GitHub 文件页点击 **Download raw file（下载原始文件）**。
2. 保存为 `.html` 文件，用 Chrome、Edge、Firefox 等浏览器打开。
3. 也可以克隆或下载整个仓库，直接打开本目录下 `zh-CN/JR_Music_Studio_Beginner_Guide_CN.html`。

截图和样式均内嵌在单个文件中，可以离线阅读。GitHub 文件页本身显示源码，不会直接运行 HTML。

### 阅读提示

- 截图中的工程、伙伴与 MCP 名称是操作示例，以自己的部署为准。
- “10 分钟快速路径”是入门阅读指引；实际创作和生成耗时取决于模型及硬件。
- Style＋歌词生成的候选需要先点 **「以生成谱继续修改」**，另存可编辑候选后，才能使用谱面修改和导出。
- 保留约束保护创作输入；局部修改后仍重新生成音频，不保证其余录音片段完全不变。
- 安装要求和当前能力以仓库 [README](../README.md) 为准。

这里只收录明确授权公开的攻略；内部架构、详细设计、维护手册与私有部署资料不在此目录中。
